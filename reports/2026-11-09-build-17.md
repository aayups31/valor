The original run used runner revision `ad95638`. Follow-up tests verify that an invalid model operation never reaches SQLite and that an observer error is recorded without vetoing a valid worker action. The latter change affects the error path, which did not occur in the measured trial. To repeat on a machine with the same model already installed, run `python scripts/Run-OllamaShadow.py artifacts/my-shadow-trial` from the checkout in VALOR's Python environment. The output directory must be new. Model outputs can vary across runs and hardware.

This trial covers one model, one fixture schema, two operations and no concurrent writers. It measures the correctness of the explicit SQLite observer. It does not validate learned fear, compare decision quality against other proctors, or establish efficacy on a customer's workflow. VALOR issued warnings and the worker still executed.
