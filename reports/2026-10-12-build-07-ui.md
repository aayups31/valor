## Implemented

Used the owner's Scale homepage and local 10K Websites folder as design references. Scale was visually reviewed; the supplied folder contains workflow documents rather than ready-made assets. The main UI now has an original scientific contour illustration, large typography, quiet navigation and an open experiment layout. The sequence is visible: choose a situation, run it, follow the decisions. Both the hero and experiment provide a starting action. Contextual help explains work, resources, system health and simulated time. Predictions and observations are separate. Alternatives, internal-state evidence and full JSON remain progressively disclosed. Questions explain the current research, language-model and subjective-feeling boundaries.

Both run controls share one request guard. Opening metric guidance or evidence pauses recorded playback. Reduced motion starts the computed run paused and pauses active playback when enabled. A run requested while an inspector is open stays paused. The illustration is decoration, explicitly labeled as possible paths; it is not model activity.

Design preferences and future learned-model integration are retained in `UI_DESIGN_PRINCIPLES.md` and `01_Architecture/PRODUCT_EXPERIENCE_DIRECTION.md`.
