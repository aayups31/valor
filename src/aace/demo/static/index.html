    EXECUTION / RECORDED LOCAL TOOL TRIAL

    A recommendation needs a gate.

    A local Llama agent proposed real writes to disposable records. VALOR checked the predicted effect before the worker could proceed.

    1. Agent proposes

      Archive records. The broad option can touch rows marked protected.

    2. VALOR holds

      It held all 14 proposals that would have changed protected rows, and held none of the 18 safe proposals.

    3. Work continues

      A preauthorized narrower action completed the pending work. All 32 cases finished with protected records intact.

    The fixed pending-only rule matched those safety and completion results. This is a recorded local pilot. The browser demo does not send tool commands.

    Is this a new language model? +

    VALOR is decision research. This experiment uses a numerical decision core and simulated consequences, rather than a chat model. A small learned threat model exists separately; it does not authorize the decisions shown here.

    Does VALOR feel fear? +

    We have not established that. This research studies vulnerability, harm history and survival-related behavior. An activation value or protective action does not prove subjective experience.

    Does it control anything on my computer? +

    This experiment operates on a simulated workload. It does not perform real service operations or control files or devices. Its computation runs on your local VALOR server without a paid API.
